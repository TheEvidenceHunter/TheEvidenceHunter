### 👨‍💻 About Me | نبذة عني
I am Ameer R. Al-Jubouri (TheEvidenceHunter), a Cybersecurity Engineering Technologies graduate from the University of Hilla and a Certified Threat Intelligence & Governance Analyst (CTIGA). I specialize in Digital Forensics & Incident Response (DFIR), memory analysis, proactive threat hunting, and developing automated, AI-assisted security solutions adhering to global forensic standards.

أمير راسم الجبوري (TheEvidenceHunter) — مهندس تقنيات الأمن السيبراني، ومحلل معتمد في استخبارات التهديدات والحوكمة (CTIGA). متخصص في التحقيق الجنائي الرقمي والاستجابة للحوادث، وتحليل الذاكرة، وصيد التهديدات الاستباقي، وتطوير حلول أمنية مؤتمتة وفق المعايير العالمية.

### 🌐 Core Domains & Global Standards | مجالات التخصص والمعايير العالمية

* 🔍 Digital Forensics & Incident Response (DFIR): Conducting non-destructive evidence acquisition, cryptographic integrity verification (MD5/SHA-256), timeline reconstruction, and strict chain-of-custody documentation.
* 🧠 Advanced Memory & Malware Forensics: Deep-dive volatile memory analysis, anomalous process-tree investigation, and behavioral malware dissection using industry-standard frameworks.
* 🎯 Cyber Threat Intelligence & MITRE ATT&CK: Proactive threat hunting, adversary TTP mapping against the MITRE ATT&CK framework, and automated OSINT enrichment.
* 🛡️ Security Operations (SOC) & Defense: Architecting full-visibility monitoring pipelines integrating SIEM/XDR, endpoint telemetry, and network intrusion detection systems.
